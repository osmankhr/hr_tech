## Keeping these current

These docs were generated by deep-diving the codebase on 2026-09-09. They are **not** auto-updated.
When you (or an AI assistant) make a structural change — new API route, new script, new major
component, schema change, changed conventions — update the relevant file in the same session as a
quick pass, not as a separate task. Treat drift here the same as you'd treat an outdated code comment.

For narrower, frequently-changing facts (e.g. "which endpoint returns what shape today"), prefer
checking the actual source — these docs are for orientation and architecture, not as a substitute
for reading code before editing it.
